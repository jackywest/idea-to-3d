# Contributing

Small, focused pull requests are welcome: new `kit` helpers, new example scenes, clearer docs, bug fixes.

- Run `npm i && npm test` before opening a PR (browser tests need Chrome or Chromium; set `CHROME_PATH` if needed).
- Keep the zero-network, deterministic contract (see `skills/idea-to-3d/references/scene-contract.md`).
- No binary assets, no copied code. Say where an idea comes from.
- By contributing you agree that your work is released under the MIT licence.
